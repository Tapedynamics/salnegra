Áreas de Mejora

Alt Text de Imágenes Incompleto

El Problema

Solo algunas imágenes tienen alt text (ej. "Steak" para la imagen principal). Muchas imágenes, especialmente las del feed de Instagram y de la galería, carecen de descripciones apropiadas.

Solución

Agregar alt text descriptivos a todas las imágenes:

<!-- Ejemplos de alt text para Empire --> <!-- Platos --> <img src="steak.jpg" alt="Ribeye steak premium con guarniciones en el restaurante Empire Tenerife"> <img src="wellington.jpg" alt="Beef Wellington con costra dorada, especialidad Empire Playa de las Americas"> <img src="brunch.jpg" alt="Full English Breakfast brunch dominical Empire Restaurant"> <!-- Ambiente --> <img src="interior.jpg" alt="Sala elegante del restaurante britanico Empire en Tenerife Sur">
Impacto: ALTO - Google Imágenes y Accesibilidad

Schema Restaurant Faltante

El Problema

Falta el schema específico Restaurant con horarios, menú, reservas y reseñas. Esto limita la aparición en el Local Pack de Google y Google Maps.

{ "@context": "https://schema.org", "@type": "Restaurant", "name": "Empire Restaurant Tenerife", "image": "https://empirerestauranttenerife.com/images/empire.jpg", "description": "Modern British steakhouse in Playa de las Americas", "servesCuisine": ["British", "Steakhouse", "International"], "priceRange": "$$$", "address": { "@type": "PostalAddress", "streetAddress": "Safari Centre", "addressLocality": "Playa de las Americas", "postalCode": "38660", "addressCountry": "ES" }, "geo": { "@type": "GeoCoordinates", "latitude": 28.0523, "longitude": -16.7262 }, "telephone": "+34822621137", "openingHoursSpecification": [ { "@type": "OpeningHoursSpecification", "dayOfWeek": ["Monday","Tuesday","Wednesday","Thursday","Friday","Saturday","Sunday"], "opens": "13:30", "closes": "23:00" } ], "menu": "https://empirerestauranttenerife.com/menu/", "acceptsReservations": "True", "aggregateRating": { "@type": "AggregateRating", "ratingValue": "4.8", "reviewCount": "XXX" } }
Impacto: MEDIO - SEO Local

Breadcrumb Mínimo

El Problema

El breadcrumb schema presente incluye solo "Home". Falta la estructura completa que ayudaría a la navegación y la indexación de las páginas internas.

Solución

Implementar breadcrumb completo en todas las páginas:

Home > Menu > Menu Principal Home > Reservas Home > Brunch Home > Sobre Nosotros
Impacto: BAJO - UX e Indexación

Rendimiento Scripts GDPR

El Problema

Detectadas duplicaciones en los scripts GDPR/cookie consent que pueden impactar los Core Web Vitals, especialmente LCP y TBT.

Solución

Auditoría de los scripts de consentimiento y eliminación de duplicados. Cargar cookie banner de forma asíncrona para no bloquear el renderizado.

Impacto: BAJO - Rendimiento

Plan de Acción

PRIORIDAD ALTA

1. Completar Alt Text de Imágenes

Auditoría de todas las imágenes del sitio. Agregar alt text descriptivos con keywords relevantes (British cuisine, steakhouse, Tenerife, Playa de las Americas). Enfoque en imágenes de platos, ambiente y feed de Instagram.

PRIORIDAD MEDIA

2. Implementar Schema Restaurant

Agregar structured data Restaurant completo con horarios, menú, teléfono, reservas y reseñas agregadas de TripAdvisor/Google.

PRIORIDAD MEDIA

3. Expandir Breadcrumb

Implementar navegación breadcrumb completa en todas las páginas internas para mejorar UX y señales de estructura a Google.

PRIORIDAD BAJA

4. Optimizar Cookie Scripts

Eliminar duplicaciones en los scripts GDPR. Implementar carga asíncrona del cookie banner para mejorar Core Web Vitals.

PRIORIDAD BAJA

5. FAQ Schema para Brunch/Menú

Agregar FAQ schema con preguntas comunes: horarios brunch, dress code, reservas grupos, menús especiales, opciones vegetarianas.
