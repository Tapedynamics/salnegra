Problemas Críticos

1. H1 NO VISIBLE EN HTML ESTÁTICO (DIVI DINÁMICO)

El H1 de la página principal no es visible en el HTML estático que reciben los crawlers. Divi carga mucho contenido dinámicamente vía JavaScript, lo que significa que Googlebot puede no ver el encabezado principal en su primer rastreo.

Impacto: El H1 es una señal de relevancia fundamental para Google. Si no está en el HTML inicial, la página pierde posicionamiento.

Solución: Asegurar que el H1 esté presente en el HTML estático, no solo en módulos Divi dinámicos.

<h1>Correduría de Seguros en Canarias - Contrata tu Seguro Online | PBF Seguros</h1>

2. SIN HREFLANG TAGS PARA VERSIÓN EN INGLÉS

El sitio tiene versiones en español e inglés, pero no se detectan etiquetas hreflang que indiquen a Google la relación entre ambas versiones. Esto puede causar que Google indexe la versión incorrecta para cada usuario o trate las versiones como contenido duplicado.

Solución:

<link rel="alternate" hreflang="es" href="https://www.pbfseguros.com/" /> <link rel="alternate" hreflang="en" href="https://www.pbfseguros.com/en/" /> <link rel="alternate" hreflang="x-default" href="https://www.pbfseguros.com/" />

3. SIN LANDING PAGES LOCALES POR OFICINA

Con 5 oficinas físicas en distintas islas, PBF Seguros debería tener una landing page dedicada por cada ubicación con dirección, teléfono, horarios y Schema LocalBusiness individual. Actualmente toda la información local parece estar condensada en una sola página.

Impacto: Pierde posicionamiento en búsquedas locales como "seguros en Corralejo", "correduría de seguros Adeje", etc.

Solución: Crear páginas /oficina-corralejo/, /oficina-adeje/, /oficina-tenerife-sur/, etc. con Schema LocalBusiness individual.

<script type="application/ld+json"> { "@context": "https://schema.org", "@type": "InsuranceAgency", "name": "PBF Seguros - Oficina Corralejo", "image": "https://www.pbfseguros.com/img/oficina-corralejo.jpg", "url": "https://www.pbfseguros.com/oficina-corralejo/", "telephone": "+34928XXXXXX", "address": { "@type": "PostalAddress", "streetAddress": "Dirección de la oficina", "addressLocality": "Corralejo", "addressRegion": "Fuerteventura", "postalCode": "35660", "addressCountry": "ES" }, "openingHoursSpecification": [{ "@type": "OpeningHoursSpecification", "dayOfWeek": ["Monday","Tuesday","Wednesday","Thursday","Friday"], "opens": "09:00", "closes": "18:00" }] } </script>

Problemas Adicionales

1. RENDIMIENTO DIVI - CORE WEB VITALS

El tema Divi es conocido por generar HTML/CSS pesado con muchas capas de divs anidados. Esto afecta directamente los Core Web Vitals (LCP, CLS, FID), que son factores de ranking desde 2021. El JavaScript de Divi puede bloquear el renderizado inicial.

Solución: Activar las opciones de rendimiento avanzado de Divi (Critical CSS, defer JS), implementar un plugin de caché (WP Rocket o LiteSpeed Cache) y optimizar imágenes con WebP.

2. FAVICON NO DECLARADO EN HEAD

No se detecta una declaración explícita de favicon en el <head>. Aunque los navegadores lo buscan automáticamente, declararlo explícitamente mejora la experiencia y evita errores 404 en logs del servidor.

<link rel="icon" type="image/x-icon" href="/favicon.ico" /> <link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png" />

3. SCHEMA TIPO GENÉRICO (ORGANIZATION)

El Schema.org actual usa Organization genérico. Para una correduría de seguros, debería ser InsuranceAgency, que es un tipo más específico reconocido por Google para mostrar rich snippets relevantes.

Solución: Cambiar "@type": "Organization" a "@type": "InsuranceAgency" en el JSON-LD.

4. IMÁGENES SIN ALT TEXT DESCRIPTIVO

Las imágenes detectadas carecen de atributos alt descriptivos. Para una web de seguros, los alt text deberían describir los servicios y ubicaciones para reforzar el SEO.

5. SIN FAQ SCHEMA

El sector seguros genera muchas preguntas frecuentes ("¿Qué cubre el seguro de hogar?", "¿Cómo contratar seguro online?"). Una sección FAQ con Schema FAQPage generaría rich snippets muy valiosos en las SERPs.

6. FOOTER CARGADO DINÁMICAMENTE

El contenido del footer (con enlaces legales, aviso legal, política de privacidad) no es visible en el HTML estático inicial. Esto puede afectar la indexación de enlaces importantes.

7. GOOGLE ANALYTICS NO DETECTADO EN CARGA INICIAL

No se detecta código de Google Analytics o GTM en el HTML inicial. Puede estar cargado vía Tag Manager o de forma diferida, pero debería verificarse que el tracking funciona correctamente.
