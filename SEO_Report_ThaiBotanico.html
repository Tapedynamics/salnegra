Problemas a Resolver

CRÍTICO: Alt Text de Imágenes Ausente

El Problema

Las imágenes de platos tailandeses, ambiente tropical y cócteles carecen de alt text descriptivos. Esto es particularmente grave para un restaurante con fuerte atractivo visual como Thai Botanico.

<!-- Ejemplos de alt text para Thai Botanico --> <!-- Platos thai --> <img src="padthai.jpg" alt="Pad Thai con gambas y cacahuetes, cocina tailandesa auténtica Tenerife"> <img src="curry.jpg" alt="Green curry thai con pollo y verduras en Thai Botanico"> <img src="tomyum.jpg" alt="Tom Yum soup picante con gambas, especialidad Thai Botanico Playa de las Américas"> <!-- Ambiente --> <img src="interior.jpg" alt="Sala restaurante Thai Botanico con plantas tropicales y atmósfera asiática"> <!-- Cocktail --> <img src="cocktail.jpg" alt="Cóctel tropical Thai Botanico con decoración exótica">
Impacto: CRÍTICO - Google Imágenes y Accesibilidad

Variación de Keywords Limitada

El Problema

El contenido se apoya principalmente en el nombre de marca. Faltan variaciones de keywords para capturar búsquedas como "restaurante tailandés Tenerife", "thai food Playa de las Américas", "best pad thai Canary Islands".

Solución

Enriquecer los textos con keywords long-tail:

  • "authentic Thai restaurant Tenerife South"
  • "best green curry Playa de las Americas"
  • "Thai food delivery Tenerife"
  • "romantic Thai dinner Canary Islands"
Impacto: MEDIO - Ranking Long-tail Keywords

Schema Restaurant Faltante

El Problema

Falta el schema LocalBusiness/Restaurant específico con tipo de cocina (Thai), horarios, coordenadas GPS y reseñas agregadas.

{ "@context": "https://schema.org", "@type": "Restaurant", "name": "Thai Botanico", "image": "https://thaibotanicotenerife.com/images/thai-botanico.jpg", "servesCuisine": ["Thai", "Asian"], "priceRange": "$$", "address": { "@type": "PostalAddress", "streetAddress": "...", "addressLocality": "Playa de las Americas", "postalCode": "38660", "addressCountry": "ES" }, "telephone": "+34822621136", "openingHoursSpecification": [...], "menu": "https://thaibotanicotenerife.com/menu/", "acceptsReservations": "True" }
Impacto: MEDIO - SEO Local

Rendimiento Scripts

El Problema

Heavy script bloat detectado: Google Tag Manager, consent frameworks múltiples. Esto puede impactar los Core Web Vitals, especialmente LCP y TBT.

Impacto: BAJO-MEDIO - Rendimiento

Plan de Acción

PRIORIDAD ALTA

1. Alt Text para Todas las Imágenes

Añadir descripciones a todas las fotos: platos thai (pad thai, curry, tom yum), ambiente tropical, cócteles. Incluir keywords: Thai, Tenerife, Playa de las Américas.

PRIORIDAD MEDIA

2. Enriquecer Contenidos con Keywords

Expandir textos con variaciones de keywords long-tail. Crear secciones dedicadas para platos signature (Pad Thai, Green Curry, Tom Yum).

PRIORIDAD MEDIA

3. Schema Restaurant Completo

Implementar structured data Restaurant con "servesCuisine": "Thai", horarios, menu links, teléfono y coordenadas GPS.

PRIORIDAD BAJA

4. Optimizar Scripts

Auditoría de los scripts de tracking. Cargar GTM y consent de modo asíncrono. Target: mejorar LCP bajo 2.5 segundos.
