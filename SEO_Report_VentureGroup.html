Áreas de Mejora

Rendimiento JavaScript

El Problema

El sitio carga múltiples scripts de tracking pesados: Google Tag Manager, Bloomreach, Exponea. CSS inline extensivo (~50KB). Esto puede impactar los Core Web Vitals, especialmente LCP y FID.

Solución

1. Cargar scripts de analytics de forma asíncrona
2. Implementar critical CSS inline, resto en archivo externo
3. Defer para JavaScript no crítico
4. Evaluar consolidación de tracking tools

<!-- Carga asíncrona optimizada --> <script src="gtm.js" async defer></script> <!-- Critical CSS inline, resto diferido --> <link rel="preload" href="styles.css" as="style" onload="this.rel='stylesheet'">
Impacto: MEDIO - Core Web Vitals

Schema LocalBusiness Faltante

El Problema

Falta el schema LocalBusiness/Restaurant para los restaurantes individuales. Esto limita la visibilidad en búsquedas locales y Google Maps.

Solución

Agregar schema Restaurant para cada marca con:

  • Nombre, dirección, teléfono
  • Horarios de apertura
  • Tipo de cocina
  • Rango de precio
  • Enlace de reservas
{ "@context": "https://schema.org", "@type": "Restaurant", "name": "Bianco Ristorante", "image": "https://venturegrouptenerife.com/bianco.jpg", "servesCuisine": "Italian", "priceRange": "$$", "address": { "@type": "PostalAddress", "streetAddress": "CC Safari Centre", "addressLocality": "Playa de las Americas", "addressCountry": "ES" }, "telephone": "+34...", "openingHoursSpecification": {...} }
Impacto: MEDIO - SEO Local

Número de Teléfono No Visible

El Problema

El número de teléfono central del grupo no es inmediatamente visible en la homepage. Solo email disponible (MyVenture@VentureGroup88.com).

Solución

Agregar número de teléfono en el header/footer con schema ContactPoint. Implementar click-to-call para móvil.

Impacto: BAJO - UX/Conversiones

Plan de Acción

PRIORIDAD MEDIA

1. Optimización de Rendimiento

Auditoría completa con PageSpeed Insights. Implementar lazy loading avanzado, critical CSS, y defer para scripts no esenciales. Objetivo: LCP < 2.5s.

PRIORIDAD MEDIA

2. Schema LocalBusiness para Restaurantes

Crear schema Restaurant para cada marca del grupo. Incluir horarios, menús, precios y enlaces de reservas directas.

PRIORIDAD BAJA

3. Contactos Visibles

Agregar número telefónico central en el footer con markup ContactPoint. Implementar WhatsApp Business para soporte rápido.

PRIORIDAD BAJA

4. Schema FAQ

Agregar sección FAQ con schema markup para preguntas comunes: reservas, código de vestimenta, menús especiales, eventos privados.

Veredicto Final

Venture Group Tenerife tiene un sitio con excelente base SEO. Schema markup, meta tags y estructura de encabezados están ya bien implementados. Las mejoras sugeridas son optimizaciones para pasar de "bueno" a "excelente".
