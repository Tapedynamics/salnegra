Problemas Críticos

1. CERTIFICADO SSL ROTO (HTTPS NO FUNCIONA)

El sitio web falla al intentar conectar vía HTTPS. El navegador muestra error de certificado SSL. Esto es un factor de ranking negativo directo para Google desde 2014, y Chrome muestra advertencia "No seguro" a los visitantes.

Todas las URLs internas y Open Graph apuntan a http:// en lugar de https://.

Impacto: Google penaliza sitios sin HTTPS. Los usuarios ven "No seguro" y abandonan. Las conversiones caen significativamente.

Solución: Instalar y configurar un certificado SSL válido (Let's Encrypt gratuito) y redirigir todo el tráfico HTTP a HTTPS.

2. SIN META DESCRIPTION

La página principal no tiene etiqueta meta description. Google generará automáticamente un snippet con texto aleatorio de la página, que incluirá nombres de badges como "Restaurant Guru Recommended".

La página del menú tiene <meta type="description"> en lugar de <meta name="description">, lo cual es sintaxis incorrecta y Google lo ignora.

Solución:

<!-- Homepage --> <meta name="description" content="Akustito Restaurante y Coctelería en Los Cristianos, Tenerife. Cocina internacional, cócteles de autor y música en vivo. Martes a Sábado. Reservas: +34 650 57 67 38" /> <!-- Menu page - CORREGIR type por name --> <meta name="description" content="Carta de Akustito Restaurante - Los Cristianos. Entrantes, carnes, pescados y cócteles de autor. Disponible en español, inglés y francés." />

3. SIN ETIQUETA H1

La página principal no tiene ningún H1. El logo es una imagen sin texto alternativo y no hay encabezado de texto. Los motores de búsqueda dependen del H1 para entender el tema principal de la página.

Solución:

<h1>Akustito Restaurante y Coctelería - Los Cristianos, Tenerife</h1> <!-- Puede ir visualmente oculto si interfiere con el diseño del logo -->

4. SIN SCHEMA MARKUP (DATOS ESTRUCTURADOS)

Cero datos estructurados Schema.org en todo el sitio. Para un restaurante con tan buenas reseñas, esto es una oportunidad enorme perdida: sin rich snippets, sin estrellas en Google, sin horarios en los resultados de búsqueda.

Solución:

<script type="application/ld+json"> { "@context": "https://schema.org", "@type": "Restaurant", "name": "Akustito Restaurante y Coctelería", "image": "https://akustitorestaurante.es/img/akustito2-og.jpg", "url": "https://akustitorestaurante.es", "telephone": "+34922898027", "address": { "@type": "PostalAddress", "streetAddress": "Calle Jesús Domínguez Grillo, 12", "addressLocality": "Los Cristianos", "addressRegion": "Tenerife", "postalCode": "38650", "addressCountry": "ES" }, "geo": { "@type": "GeoCoordinates", "latitude": 28.0507622, "longitude": -16.720099 }, "openingHoursSpecification": [ { "@type": "OpeningHoursSpecification", "dayOfWeek": ["Tuesday","Wednesday","Thursday","Friday","Saturday"], "opens": "17:30", "closes": "23:30" } ], "servesCuisine": ["International", "Cocktails"], "priceRange": "$$", "aggregateRating": { "@type": "AggregateRating", "ratingValue": "4.8", "reviewCount": "1506" }, "hasMenu": "https://akustitorestaurante.es/menu.php" } </script>

5. MENÚ INVISIBLE PARA GOOGLE (JAVASCRIPT + GOOGLE SHEETS)

El menú del restaurante se carga dinámicamente mediante JavaScript desde Google Sheets CSV. Aunque Googlebot puede ejecutar JavaScript, este enfoque presenta limitaciones SEO significativas: el contenido solo se indexa en el segundo crawl (con retraso), si el CSV tarda en cargar Google puede no verlo, y el contenido no aparece en el HTML inicial.

Aunque es práctico para actualizar el menú, reduce significativamente la visibilidad SEO.

Solución: Implementar Server-Side Rendering (SSR) del menú con PHP (ya usan menu.php) que lea el CSV y genere HTML estático. Mantener la carga dinámica como fallback.

6. ATRIBUTO LANG INCORRECTO EN HOMEPAGE

La homepage tiene <html lang="en"> cuando el contenido principal es bilingüe español/inglés y el restaurante está en España. La página del menú correctamente usa lang="es".

Solución: Cambiar a <html lang="es"> en la homepage y añadir hreflang tags para las versiones en otros idiomas.

Problemas Adicionales

1. SIN GOOGLE ANALYTICS NI TRACKING

No hay Google Analytics, Google Tag Manager ni ningún sistema de tracking instalado. Es imposible medir el tráfico, las conversiones o el comportamiento de los usuarios.

Solución: Instalar GA4 con eventos de clic en WhatsApp, teléfono y página de menú.

2. IMÁGENES SIN ALT TEXT

El logo principal (img/logo.png) y la imagen de footer (img/akustito-footer.jpg) no tienen atributo alt. Las banderas de idiomas tampoco tienen alt descriptivo.

Solución:

<img src="img/logo.png" alt="Akustito Restaurante y Coctelería - Los Cristianos" class="img-fluid" /> <img src="img/akustito-footer.jpg" alt="Interior de Akustito Restaurante - ambiente acogedor" class="img-fluid" />

3. ENLACES TEL: MALFORMADOS

El segundo enlace de teléfono usa href="0034922898027" sin el protocolo tel:. Esto no funciona en dispositivos móviles.

Solución: Cambiar a href="tel:+34922898027"

4. ERROR TIPOGRÁFICO EN CSS

@media screen and (max-widht:680px) - "widht" debería ser "width". Esta media query no funciona, lo que puede causar problemas de diseño en móviles.

5. SIN HREFLANG TAGS

Con 3 idiomas (ES/EN/FR), faltan las etiquetas hreflang para evitar contenido duplicado y dirigir a los usuarios al idioma correcto.

<link rel="alternate" hreflang="es" href="https://akustitorestaurante.es/" /> <link rel="alternate" hreflang="en" href="https://akustitorestaurante.es/menu.php?lang=en" /> <link rel="alternate" hreflang="fr" href="https://akustitorestaurante.es/menu.php?lang=fr" /> <link rel="alternate" hreflang="x-default" href="https://akustitorestaurante.es/" />

6. SIN CANONICAL TAG

No hay etiqueta canonical en ninguna página. Con 3 versiones de idioma del menú, Google podría interpretar contenido duplicado.

7. CONTENIDO TEXTUAL MUY ESCASO

La homepage consiste principalmente en badges de premios, banderas de idioma y datos de contacto. No hay texto descriptivo sobre el restaurante, su historia, su filosofía culinaria ni sus platos estrella. Google necesita contenido textual para posicionar.

8. VERSIONES DE BOOTSTRAP INCONSISTENTES

La homepage carga Bootstrap 4.6.1 y la página del menú carga Bootstrap 4.0.0. Esto puede causar inconsistencias visuales y cargar CSS innecesario.
