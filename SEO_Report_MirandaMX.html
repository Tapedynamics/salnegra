Problemas Detectados

1. BAJO NUMERO DE SEGUIDORES EN INSTAGRAM

Solo 166 seguidores en @mirandamxtf. Para un restaurante mexicano con platos visuales (tacos, margaritas coloridas), hay potencial para mucho mas engagement.

Solucion: Estrategia de contenido visual: videos de preparacion de tacos, fotos de margaritas, contenido festivo mexicano, colaboraciones con influencers locales.

2. FALTA KEYWORD "TEX-MEX"

El sitio no menciona "Tex-Mex" aunque ofrece ese estilo de cocina. Es una keyword con busquedas relevantes.

Keywords a incluir:

  • "tex mex tenerife"
  • "comida mexicana costa adeje"
  • "tacos tenerife sur"
  • "fajitas tenerife"

3. SIN BLOG O CONTENIDO SEO ADICIONAL

No hay seccion de blog. Oportunidad perdida para posicionar articulos como "mejores restaurantes mexicanos en Tenerife" o "recetas de margaritas".

4. FALTA HREFLANG VERIFICABLE

Con 2 idiomas (ES/EN), las etiquetas hreflang deben estar correctamente implementadas para evitar contenido duplicado en Google.

<link rel="alternate" hreflang="es" href="https://mirandamx.com/" /> <link rel="alternate" hreflang="en" href="https://mirandamx.com/en/" /> <link rel="alternate" hreflang="x-default" href="https://mirandamx.com/" />

5. SIN SCHEMA REVIEW/RATING

Aunque hay enlace a TripAdvisor, no hay Schema AggregateRating implementado para mostrar estrellas en resultados de Google.

"aggregateRating": { "@type": "AggregateRating", "ratingValue": "4.5", "reviewCount": "150" }

6. SLIDER REVOLUTION - POSIBLE IMPACTO EN VELOCIDAD

El uso de Slider Revolution y jQuery puede impactar los tiempos de carga. Considerar optimizacion o alternativas mas ligeras.
