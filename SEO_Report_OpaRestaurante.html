Problemas Críticos

Página del Menú sin H1

La página /es/menu/ no tiene una etiqueta H1 apropiada. El título "Menú" es demasiado genérico y falta la keyword principal.

Impacto: Google no identifica claramente el tema de la página del menú. Oportunidad perdida para rankear en "menú restaurante griego Tenerife".

Meta Description de la Página del Menú Ausente

La página del menú parece no tener una meta description optimizada específica.

Impacto: CTR reducido para búsquedas específicas del menú. Google genera snippets automáticos.

Falta Schema Restaurant Específico

A pesar de que el schema Organization está presente, falta el schema específico "Restaurant" con:

  • servesCuisine: "Greek", "Mediterranean"
  • priceRange
  • openingHours estructurados
  • acceptsReservations
  • menu URL
Impacto: Rich snippets limitados. No aparece tipo de cocina, horarios ni precios en los resultados de Google.

Textos Alt de Imágenes Parciales

Algunas imágenes de platos tienen texto alt pero muchas carecen de él o tienen descripciones genéricas.

Impacto: Oportunidad parcialmente perdida para Google Imágenes. Accesibilidad no óptima.
