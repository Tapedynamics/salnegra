Áreas de Mejora Identificadas

⚠️ Schema LocalBusiness en Página de Contacto

Problema: La página contacto.html tiene NAP y Google Maps, pero sin Schema LocalBusiness.

Impacto: Menor visibilidad en búsquedas locales y Google Maps.

Solución:

<script type="application/ld+json"> { "@context": "https://schema.org", "@type": "LocalBusiness", "name": "Sal Negra Tenerife", "address": { "@type": "PostalAddress", "streetAddress": "Avda. La Habana, CC San Telmo, Local 13b", "addressLocality": "Los Cristianos", "postalCode": "38650", "addressCountry": "ES" }, "telephone": "+34 922 30 69 58", "openingHours": "Mo-Su 09:00-17:00" } </script>

⚠️ Accesibilidad CSS - Focus States Ausentes

Problema encontrado en style.css:

  • No hay :focus-visible para navegación por teclado
  • Carousel no navegable por teclado
  • Falta prefers-reduced-motion para animaciones
  • Lightbox sin atributos ARIA

Solución:

/* Añadir en style.css */ :focus-visible { outline: 3px solid #c41e3a; outline-offset: 2px; } @media (prefers-reduced-motion: reduce) { * { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; } }

⚠️ H1 Semántico en Homepage

Problema: El H1 principal es una imagen del logo, no hay H1 textual visible.

Solución: Añadir H1 con texto real (puede ser visualmente oculto con CSS si se desea mantener el diseño):

<h1 class="sr-only">Sal Negra Tenerife - Restaurante de Mariscos y Tapas</h1> /* CSS */ .sr-only { position: absolute; width: 1px; height: 1px; padding: 0; margin: -1px; overflow: hidden; clip: rect(0, 0, 0, 0); border: 0; }

⚠️ Schema en Menús Especiales

Problema: La página menus-especiales.html tiene contenido excelente pero sin Schema Menu.

Oportunidad: Añadir Schema para los 3 menús de grupo (45€, 50€, 60€).

⚠️ Performance CSS

Problemas detectados:

  • Google Fonts sin font-display: swap
  • Imágenes sin loading="lazy"
  • Carousel 3D carga todas las imágenes simultáneamente

💡 Oportunidad: AggregateRating Schema

El sitio NO tiene sección de reseñas ni Schema de valoraciones. Implementar esto permitiría mostrar estrellas en los resultados de Google.

{ "@type": "Restaurant", "aggregateRating": { "@type": "AggregateRating", "ratingValue": "4.7", "reviewCount": "185" } }
