Problemas a Resolver

CRÍTICO: Alt Text de Imágenes Ausentes (~95%)

El Problema

La casi totalidad de las imágenes carece de alt text descriptivos. Solo el logo tiene un atributo alt ("Imperial Taipan Restaurant & Teppanyaki"). Todas las fotos de platos, ambiente y teppanyaki son invisibles para Google Imágenes.

<!-- Ejemplos de alt text para Imperial Tai-Pan --> <!-- Platos chinos --> <img src="duck.jpg" alt="Pato a la pekinesa crujiente servido en el restaurante Imperial Tai-Pan Tenerife"> <img src="dimsum.jpg" alt="Dim sum al vapor, cocina china gourmet Playa de las Américas"> <!-- Sushi --> <img src="sushi.jpg" alt="Sushi mixto con salmón y atún fresco Imperial Tai-Pan"> <!-- Teppanyaki --> <img src="teppanyaki.jpg" alt="Chef teppanyaki cocinando en vivo en la mesa, espectáculo culinario Tenerife">
Impacto: CRÍTICO - Google Imágenes y Accesibilidad

Schema Restaurant Ausente

El Problema

Falta el schema LocalBusiness/Restaurant con horarios, menú, reservas, coordenadas GPS y reseñas agregadas. Esto limita la visibilidad en el Local Pack de Google y Google Maps.

{ "@context": "https://schema.org", "@type": "Restaurant", "name": "Imperial Tai-Pan", "image": "https://imperialtaipanrestaurant.com/images/taipan.jpg", "servesCuisine": ["Chinese", "Japanese", "Sushi", "Teppanyaki"], "priceRange": "$$$", "address": { "@type": "PostalAddress", "streetAddress": "Safari Centre", "addressLocality": "Playa de las Americas", "postalCode": "38660", "addressCountry": "ES" }, "geo": { "@type": "GeoCoordinates", "latitude": 28.0523, "longitude": -16.7262 }, "telephone": "+34822621138", "openingHoursSpecification": [...], "menu": "https://imperialtaipanrestaurant.com/menu/", "acceptsReservations": "True" }
Impacto: MEDIO - SEO Local

Breadcrumb Incompleto

El Problema

El BreadcrumbList schema contiene solo "Home". Falta la estructura completa para las páginas internas (Menu, Teppanyaki, Reservas, etc.).

Impacto: BAJO - Navegación y UX

Plan de Acción

PRIORIDAD ALTA

1. Alt Text para Todas las Imágenes

Auditoría completa de las imágenes. Añadir descripciones con palabras clave: cocina china, sushi, teppanyaki, Tenerife, Playa de las Américas. Enfoque en platos, show cooking y ambiente elegante.

PRIORIDAD MEDIA

2. Schema Restaurant Completo

Implementar structured data Restaurant con toda la información: 3 tipos de cocina (Chinese, Japanese, Teppanyaki), horarios, enlaces a menú, teléfono y coordenadas GPS.

PRIORIDAD MEDIA

3. FAQ Schema para Teppanyaki

Añadir FAQ schema con preguntas frecuentes sobre la experiencia teppanyaki: reserva de mesa, duración del show, opciones de menú, código de vestimenta.

PRIORIDAD BAJA

4. Expandir Breadcrumb

Completar navegación breadcrumb para todas las páginas internas del sitio para mejorar UX e indexación.

Veredicto: Buenas Bases, Optimizaciones Necesarias

Imperial Tai-Pan tiene meta tags excelentes y estructura de encabezados correcta. El problema principal es la falta casi total de alt text que limita la visibilidad en Google Imágenes. Con las intervenciones sugeridas puede alcanzar resultados excelentes.
