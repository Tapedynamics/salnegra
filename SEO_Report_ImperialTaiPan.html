Problemi da Risolvere

CRITICO: Alt Text Immagini Assenti (~95%)

Il Problema

La quasi totalita delle immagini manca di alt text descrittivi. Solo il logo ha un attributo alt ("Imperial Taipan Restaurant & Teppanyaki"). Tutte le foto di piatti, ambiente e teppanyaki sono invisibili a Google Immagini.

<!-- Esempi di alt text per Imperial Tai-Pan --> <!-- Piatti cinesi --> <img src="duck.jpg" alt="Anatra alla pechinese croccante servita al ristorante Imperial Tai-Pan Tenerife"> <img src="dimsum.jpg" alt="Dim sum al vapore, cucina cinese gourmet Playa de las Americas"> <!-- Sushi --> <img src="sushi.jpg" alt="Sushi misto con salmone e tonno fresco Imperial Tai-Pan"> <!-- Teppanyaki --> <img src="teppanyaki.jpg" alt="Chef teppanyaki che cucina dal vivo al tavolo, spettacolo culinario Tenerife">
Impatto: CRITICO - Google Immagini e Accessibilita

Schema Restaurant Mancante

Il Problema

Manca lo schema LocalBusiness/Restaurant con orari, menu, prenotazioni, coordinate GPS e recensioni aggregate. Questo limita la visibilita nel Local Pack di Google e Google Maps.

{ "@context": "https://schema.org", "@type": "Restaurant", "name": "Imperial Tai-Pan", "image": "https://imperialtaipanrestaurant.com/images/taipan.jpg", "servesCuisine": ["Chinese", "Japanese", "Sushi", "Teppanyaki"], "priceRange": "$$$", "address": { "@type": "PostalAddress", "streetAddress": "Safari Centre", "addressLocality": "Playa de las Americas", "postalCode": "38660", "addressCountry": "ES" }, "geo": { "@type": "GeoCoordinates", "latitude": 28.0523, "longitude": -16.7262 }, "telephone": "+34822621138", "openingHoursSpecification": [...], "menu": "https://imperialtaipanrestaurant.com/menu/", "acceptsReservations": "True" }
Impatto: MEDIO - SEO Locale

Breadcrumb Incompleto

Il Problema

Il BreadcrumbList schema contiene solo "Home". Manca la struttura completa per le pagine interne (Menu, Teppanyaki, Reservas, etc.).

Impatto: BASSO - Navigazione e UX

Piano d'Azione

PRIORITA ALTA

1. Alt Text per Tutte le Immagini

Audit completo delle immagini. Aggiungere descrizioni con keyword: cucina cinese, sushi, teppanyaki, Tenerife, Playa de las Americas. Focus su piatti, show cooking e ambiente elegante.

PRIORITA MEDIA

2. Schema Restaurant Completo

Implementare structured data Restaurant con tutte le informazioni: 3 tipi di cucina (Chinese, Japanese, Teppanyaki), orari, menu links, telefono e coordinate GPS.

PRIORITA MEDIA

3. FAQ Schema per Teppanyaki

Aggiungere FAQ schema con domande frequenti sull'esperienza teppanyaki: prenotazione tavolo, durata show, opzioni menu, dress code.

PRIORITA BASSA

4. Espandere Breadcrumb

Completare navigazione breadcrumb per tutte le pagine interne del sito per migliorare UX e indicizzazione.
