Problemas a Resolver

Alt Text de Imágenes Incompleto

El Problema

Muchas imágenes carecen de alt text descriptivo. Solo algunas tienen descripciones (ej. "Troque: La Caleta Tenerife restaurantes"). Fotos de platos, parrilla y mariscos no están optimizadas.

<!-- Ejemplos de alt text para Troque --> <img src="paella.jpg" alt="Paella dominical con frutos de mar Troque La Caleta Tenerife"> <img src="pintxos.jpg" alt="Pintxos vascos tradicionales en restaurante Troque"> <img src="parrilla.jpg" alt="Parrilla vasca con carnes y verduras a la brasa Troque Tenerife"> <img src="marisco.jpg" alt="Mariscos frescos de temporada cocina española La Caleta">
Impacto: ALTO - Google Imágenes

Canonical Tags No Detectados

El Problema

No se han detectado canonical tags en el head. Con WordPress/Elementor podrían existir problemas de contenido duplicado entre versiones ES/EN.

<!-- Agregar canonical tags --> <link rel="canonical" href="https://troquerestaurantetenerife.com/es/">
Impacto: MEDIO - Contenido Duplicado

Schema Restaurant Faltante

El Problema

Organization schema presente pero es "Lagarto" en lugar de "Troque". Falta schema Restaurant específico con tipo de cocina, priceRange y horarios.

Impacto: MEDIO - SEO Local

Contenido JS Dinámico

El Problema

Elementor/Elementor Pro generan contenido dinámico que podría impactar el crawling de Google. Verificar renderizado del lado del servidor.

Impacto: BAJO - Crawling

Plan de Acción

ALTA

1. Completar Alt Text de Imágenes

Agregar descripciones a todas las fotos: paella, pintxos, parrilla vasca, mariscos, ambiente. Incluir keywords: cocina española, La Caleta, Tenerife.

MEDIA

2. Verificar Canonical Tags

Comprobar presencia de canonical en todas las páginas. Asegurarse de que versiones ES/EN tengan hreflang correctos.

MEDIA

3. Corregir Schema Organization

Cambiar nombre de "Lagarto" a "Troque Restaurante". Agregar schema Restaurant con servesCuisine: ["Spanish", "Basque", "Seafood"].

BAJA

4. FAQ Schema

Agregar FAQ sobre: reservas paella domingos, menú vegetariano, eventos privados, alergias alimentarias.
