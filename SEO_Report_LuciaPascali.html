Problemas Críticos (A RESOLVER YA)

1. Meta Descriptions Ausentes en TODAS las Páginas CRÍTICO

Problema: Ninguna página del sitio tiene meta description definida. Google genera automáticamente fragmentos aleatorios del contenido.

Impacto:

  • CTR (Click-Through Rate) reducido en un 20-30%
  • Sin control sobre cómo aparece el sitio en resultados de búsqueda
  • Oportunidad perdida de "vender" el clic al usuario

Páginas afectadas:

  • Homepage - Sin meta description
  • Chi Sono - Sin meta description
  • F.A.B. Method - Sin meta description
  • Coaching - Sin meta description
  • Corsi - Sin meta description
  • Contatti - Sin meta description
  • Testimonianze - Sin meta description

2. Schema Markup Completamente Ausente CRÍTICO

Problema: El sitio no tiene NINGÚN dato estructurado Schema.org implementado.

Impacto:

  • Sin posibilidad de rich snippets en Google
  • Los 9 testimonios NO aparecerán como estrellas/reseñas
  • Información del negocio no estructurada para Google
  • Pérdida de visibilidad frente a competidores que sí lo tienen

Schemas necesarios:

  • Person - Para Lucia Pascali (coach/autor)
  • Organization - Para el negocio
  • Service - Para cada servicio ofrecido
  • Review/AggregateRating - Para los 9 testimonios
  • Course - Para los cursos
  • FAQPage - Si hay preguntas frecuentes
  • WebSite - Markup básico del sitio

3. Alt Text de Imágenes Ausente CRÍTICO

Problema: Las imágenes del sitio (25+) no tienen texto alternativo descriptivo.

Impacto:

  • Google Images no puede indexar las imágenes correctamente
  • Problemas de accesibilidad (WCAG compliance)
  • Pérdida de tráfico desde búsqueda de imágenes
  • Oportunidad perdida de keywords adicionales

Imágenes afectadas:

  • Foto de Lucia Pascali (perfil principal)
  • Imágenes de testimonios (9)
  • Logos de empresas cliente (19)
  • Iconos y gráficos del método FAB
  • Imágenes de cursos y servicios

4. Página Contatti sin Información de Contacto CRÍTICO

Problema: La página de contacto solo tiene formularios, pero NO muestra:

  • Email de contacto directo
  • Número de teléfono
  • Dirección física o ubicación
  • Mapa de Google

Impacto:

  • Imposible aparecer en búsquedas locales
  • Reduce confianza del visitante
  • Sin posibilidad de Schema LocalBusiness
  • Dificulta el contacto directo de clientes potenciales

Problemas Importantes

1. Title Tags Genéricos y No Optimizados ALTO

Problema: Los títulos siguen un patrón genérico sin keywords estratégicas.

Títulos actuales:

  • "Lucia Pascali - FAB Method" (Homepage)
  • "Chi sono - Lucia Pascali - FAB Method"
  • "The F.A.B. Method™ - Lucia Pascali - FAB Method"
  • "Coaching - Lucia Pascali - FAB Method"
  • "Corsi - Lucia Pascali - FAB Method"

Problema: No incluyen keywords como "coach professionista", "formazione leadership", "coaching aziendale", etc.

2. Estructura H1/H2 Inconsistente ALTO

Problema: Algunas páginas no tienen H1 claro o la jerarquía de encabezados es confusa.

  • Chi Sono: Falta H1 semántico principal
  • Homepage: H1 muy largo y no optimizado para keywords
  • Múltiples H2 sin estructura lógica clara

3. Testimonios sin Schema Review ALTO

Problema: Los 9 testimonios de alta calidad NO tienen markup de reseñas.

Oportunidad perdida:

  • Posibilidad de mostrar estrellas en Google
  • Rich snippets con rating agregado
  • Mayor CTR y credibilidad en SERPs

4. Cursos sin Información Completa ALTO

Problema: La página de cursos no muestra:

  • Fechas específicas de inicio
  • Precios o rango de precios
  • Duración de los cursos
  • Número de plazas disponibles

Impacto: No puede aparecer en rich snippets de "Course" ni eventos.

5. Falta Blog/Contenido Fresco MEDIO

Problema: No hay sección de blog activa con contenido regular.

Impacto:

  • Sin contenido fresco para Google
  • Pérdida de oportunidades long-tail keywords
  • Menos razones para que usuarios vuelvan
  • Competidores con blogs rankean mejor
